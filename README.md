# БӨЗ 3 · Микробиология

Сайт: https://milord-x.github.io/gtm-microbiology-kz/

14 слайдов на казахском. Небольшие номера страниц расположены справа внизу. Анимации на научных фото показывают биотерапию, производство инсулина и действие PETase. На двух слайдах разобрана статья Lu et al., Nature (2022), о FAST-PETase. Литература начинается с двух подтверждённых изданий «Қазақ университеті», затем идут научные работы.

Откройте `dist/index.html` для показа офлайн. Листание: ← →, Space, PageUp/PageDown, Home/End; номер и Enter — переход к слайду. F — полноэкранный режим. На телефоне — горизонтальный свайп. Нижней панели и кнопок навигации нет. Логотип ҚазҰУ расположен только на титулке.

Использованы реальные интернет-фотографии и научные структурные визуализации. Анимация биотерапии построена поверх микрофотографий кишечника и E. coli, с условными движениями молекул. Кнопка «Кідірту» останавливает анимацию. Фото E. coli не выдаётся за снимок SYNB1618.

`Сөйлеу_мәтіні_KK.txt` — обновлённый текст выступления для 14 слайдов. `dist/assets/sources.txt` — полный список научных и визуальных источников, авторов и лицензий.

Оба видео — по 28 секунд, без звука. Пересборка: `python scripts/make_videos.py`, требуется FFmpeg. Проверка логики: `node check.mjs`.

GitHub Pages обслуживает ветку `gh-pages`. Обновление: `git subtree push --prefix=dist origin gh-pages`.

Проверка реального браузерного отображения недоступна: browser host mcp__cua_repl не подключён.
