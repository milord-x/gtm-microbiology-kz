# БӨЗ 3 · Микробиология

Откройте `dist/index.html` в браузере. Презентация работает с диска без интернета, включая оба видео. Внешние ссылки на научные статьи требуют интернет.

18 слайдов на казахском. Фотографии и научные изображения загружены из CDC, NIH NIGMS, USDA ARS, RCSB PDB и Wellcome Collection. AI-generated фото не используются. Анимационные схемы — условные учебные модели, выполненные средствами сайта.

Управление: ← →, Space, PageUp/PageDown; F — fullscreen, M — содержание, Home/End. Номер и Enter — переход к слайду. На телефоне доступны кнопки и горизонтальный свайп. Видео запускаются вручную и при уходе со слайда останавливаются.

`Сөйлеу_мәтіні_KK.txt` — текст выступления на 7–9 минут.

`scripts/make_videos.py` — сборка двух учебных видео с локальным FFmpeg. Видео без звука, с казахскими пояснениями, каждое по 28 секунд. Это монтаж научных изображений, а не запись реального эксперимента.

Эмблема ҚазҰУ и принцип полноэкранной подачи взяты из предоставленного образца.
